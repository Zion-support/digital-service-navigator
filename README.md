# Digital Service Navigator

Conversational AI guide that helps residents find, understand and complete government digital services — multilingual, accessible and form-aware.

**Free & open-source (MIT).** Part of the [Zion AI App Network](https://ziontechgroup.com/zion-app-network/) — Batch 79: GovTech & Smart City AI.

## Features
- Conversational service finder across all departments
- Step-by-step guided form completion
- Multilingual + WCAG-accessible interface
- Document checklist generation
- Handoff to human agents with context
